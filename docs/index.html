ttv2yt

Personal automation tool that watches competitive Counter-Strike 2 matches, detects ACE highlights (5 kills in one round), cuts the clip from a local recording buffer, and uploads it as a private video to the operator's own YouTube channel for manual review and publishing.

How it works

  1. Monitors live match listings for important games.
  2. Records the official broadcast locally in a rolling buffer.
  3. On detecting a 5-kill round, exports the clip.
  4. Uploads the clip to YouTube as private via the YouTube Data API (scope youtube.upload). Nothing is ever published publicly by the tool.

This app is for personal use by its operator only. Support contact: brotheersbr@gmail.com.
